# ติดตั้ง Signal Hub เป็นแอดออนใน Home Assistant (Pi 4 แรม 1GB)

## 1) อัปโหลดขึ้น GitHub (ทำจากมือถือได้)
สร้าง repo ใหม่แบบ **Public** (HA ดึงจาก repo ส่วนตัวไม่ได้ และในโค้ดไม่มีรหัสลับ เพราะรหัสทั้งหมดตั้งในตัวเลือกของแอดออน) แล้วอัปโหลดทั้งโฟลเดอร์ `ha-signal-hub` ให้ `repository.yaml` และโฟลเดอร์ `signal_hub`
อยู่ที่รากของ repo แก้ `url` ใน `repository.yaml` เป็นที่อยู่ repo ของคุณ

## 2) เพิ่มใน Home Assistant
Settings → Add-ons → Add-on Store → ⋮ → Repositories → ใส่ที่อยู่ repo → Add → รีเฟรช → เลือก **Signal Hub** → Install
(ครั้งแรกต้อง build บน Pi ใช้เวลาหลายนาที)

## 3) ตั้งค่า (แท็บ Configuration ของแอดออน)
- `ha_notify` ชื่อบริการมือถือที่จะให้แจ้งเตือน ใส่ได้หลายเครื่อง
  หาชื่อที่ Developer tools → Actions ค้นหา `notify.mobile_app_` แล้วใส่ส่วนหลัง `notify.` เช่น `mobile_app_pixel_7`
- `watchlist` หุ้นที่ติดตามตั้งต้น (หลังจากนั้นเพิ่ม/ลบในแอปได้ ค่าที่แก้ในแอปจะถูกเก็บไว้)
- `scan_time` เวลาสแกน (ไทย) วันอังคารถึงเสาร์ · `default_strategy` กลยุทธ์ตั้งต้น · `cost_pct` ต้นทุนต่อข้าง (%)
- `notify_on_start` เปิดไว้ครั้งแรกเพื่อทดสอบ จะมีแจ้งเตือน "Signal Hub เริ่มทำงานแล้ว" เข้ามือถือตอนกด Start · `scan_on_start` สแกนทันทีตอนเริ่ม (ทดสอบเสร็จปิดทั้งสองอัน)
- `min_free_mb` แรมว่างขั้นต่ำก่อนสแกน (ค่าเริ่มต้น 250) ถ้าต่ำกว่า ระบบเลื่อนสแกนไปลองใหม่ทุก 30 นาที
- ช่องทางเสริม: `ntfy_topic`, `tg_token` + `tg_chat` (ไม่บังคับ)
- ไม่ต้องสร้างโทเคน HA ระบบเชื่อมผ่าน Supervisor เอง

## 4) เริ่มใช้
กด Start เปิดแผง **Signals** ในแถบข้างของ HA (ผ่านแอป Companion ได้) ล็อกอินด้วยบัญชี HA ไม่ต้องตั้งรหัสผ่านซ้ำ
ช่องทางแจ้งเตือนที่เลือกใช้ ถูกบันทึกในแอดออนและรวมอยู่ในการสำรองข้อมูลของ HA

## การป้องกันแรม (สำคัญกับ Pi แรม 1GB)
- ตัวที่เปิดค้างไม่โหลด pandas ส่วนการคำนวณหนักรันเป็นโปรเซสสั้น ๆ ทีละ 5 ตัว แล้วคืนแรมทันที
- โปรเซสคำนวณถูกตั้งให้ถูกปิดก่อนเมื่อแรมหมด เพื่อไม่ให้ HA ถูกปิดแทน
- ยังไม่ได้วัดบน Pi จริง ลองสังเกตแรมของ HA ช่วงสแกนครั้งแรก ถ้าเต็มบ่อย ให้ลดจำนวนหุ้นหรือเพิ่ม `min_free_mb`

## สถานะตอนนี้
หลังบ้าน, การแจ้งเตือนหลายช่องทาง และแพ็กเกจแอดออนเสร็จและทดสอบแล้ว ส่วนหน้า PWA ยังเป็นโหมดตัวอย่าง
(ยังไม่ต่อกับ API) และเมนูอื่นของเวอร์ชัน Python (ผลทดสอบ, walk-forward, ระบบเลือกเอง, AI, สแกนหุ้น) จะต่อในรอบถัดไป
